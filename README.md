# Bungalov Rezervasyon Sistemi 🏡

Bungalov rezervasyonları için geliştirilmiş kapsamlı ve modern bir web uygulamasıdır. Bu proje, kullanıcıların bungalovları detaylı bir şekilde inceleyebilecekleri, rezervasyon yapabilecekleri ve yöneticilerin bu süreçleri kolayca yönetebileceği bir altyapı sunmayı amaçlamaktadır.

## 🚀 Kullanılan Teknolojiler

- **Backend:** C# (.NET 8.0)
- **Mimari:** N-Tier Architecture (Çok Katmanlı Mimari)
- **Veritabanı:** PostgreSQL (Entity Framework Core)
- **Frontend / Arayüz:** ASP.NET Core MVC, HTML, CSS, JavaScript

## 📂 Proje Yapısı

Proje, temiz ve sürdürülebilir bir mimari ile geliştirilmektedir:
- `Bungalov.Core`: Temel varlıklar (Entities).
- `Bungalov.DataAccess`: Veritabanı işlemleri ve Repository katmanı.
- `Bungalov.Business`: İş kuralları (Business logic) ve servis katmanı.
- `Bungalov.WebUI`: Kullanıcı arayüzü ve Controller sınıfları.
